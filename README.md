# 初代野生版 ATM 系统 (ATM-System)

这是一个由大一新生在黑马学了几节课纯手工编写的 Java 控制台银行系统。

## 核心功能
1. **登录验证**：支持账户密码校验，限制错误次数。
2. **资产查询**：查看当前账户余额。
3. **存取款业务**：支持存款与取款，并包含金额合法性拦截。
4. **密码修改**：支持重置账户密码，包含防爆机制。

## 核心技术栈
* 纯原生 Java (JDK 17)
* 无框架、无数据库、纯面向过程编写
* 所有业务逻辑高度集中在 "main" 方法中

## 架构与开发心得
本项目由纯基础语法（变量、循环、判断）堆砌而成，内含多项野生操作：
* 在特定异常状态下，通过给循环变量 "i = 0" 赋值，强行让程序回到初始状态。
* 在深层嵌套循环中，通过 "a += 6" 瞬间突破循环边界，实现强制退出。
* 经历过将取款扣钱写成加钱、以及字符串 "==" 比较导致密码永远改不掉等重大 Bug 的修复。
